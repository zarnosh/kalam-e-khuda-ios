# کلامِ خدا — Urdu Bible Reader

A mobile-friendly installable PWA. Includes Urdu/English book search, 66 Bible books, chapter navigation, favorites, chapter bookmarks, last-read memory, dark mode, and local import of a licensed Bible JSON file. **The full Bible text is not included**; only add a translation whose license allows your intended use and redistribution.

## Deploy free on GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. Open repository **Settings → Pages**.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the URL GitHub provides after deployment.
6. On iPhone, open the URL in Safari → Share → Add to Home Screen.

## Bible JSON format
`{"Genesis":{"1":["Verse 1 text","Verse 2 text"]},"John":{"1":["Verse 1 text"]}}`
Imported text stays in local browser storage. This format sample is not Bible text.
